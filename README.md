# 日迹

日迹是给一个人每天用的小工具：记下花了多少钱，也给想坚持的习惯打卡。全部界面都是简体中文。

数据只存在你自己的浏览器里，没有账号，没有服务器，也不会上传。

## 功能

### 今天

- 列出进行中的习惯，点一下就能打卡或取消
- 显示今日支出，以及今天记下的几笔账
- 「记一笔」和「新建习惯」都在当前页完成

### 记账

- 记下金额、分类、可选备注，以及日期和时间（默认现在）
- 自带分类：餐饮、交通、购物、住房、娱乐、其他，也可以自己加分类
- 查看今日合计、本月合计，以及本月各分类占比
- 按日期范围和分类筛选历史记录
- 可以修改或删除每一笔

自己添加的分类，如果还没有支出用到它，可以在记账页底部删除。默认分类会一直保留。

### 习惯

- 新建、修改、归档习惯；归档后可以恢复
- 只能为今天打卡，再点一次就会取消。漏掉的日期不能补记
- 每个习惯显示当前连续天数，以及本周完成了几天
- 用一周的圆点看最近这几天有没有打卡

连续天数从今天往前数。如果今天还没打卡，就从昨天接着数；昨天也没有，连续天数就是 0。

第一次打开是空的，没有示例数据。

## 本地运行

需要 Node.js 20.19 或更高版本，也可以用 22.12 及以上。

```bash
npm install
npm run dev
```

终端会显示本地地址，用浏览器打开即可，一般是 http://localhost:5173 。

其他命令：

- `npm run build`：做类型检查并构建
- `npm run preview`：预览构建结果
- `npm test`：运行记账、打卡和本地存储相关的测试

## 数据存在哪里

浏览器 `localStorage` 的键名是 `riji.v1`。刷新页面后记录还在。

换浏览器、换设备，或清除这个网站的数据之后，记录会消失。这一版没有云同步。

想清空全部数据时，可以在浏览器开发者工具里删除键 `riji.v1`，然后刷新页面。

## 技术说明

界面用 Vite、React 和 TypeScript 写成。第一版没有后端，也没有登录。

界面字体是 Noto Sans SC 的常用字子集，放在 `public/fonts/`，按 SIL Open Font License 1.1 使用（全文见 `public/fonts/OFL.txt`）。没有收录的生僻字会回退到系统中文字体。
